## 🚀 极速上手指南

```
[ 1. 扫描首页 ] ──> [ 2. 引导录制(按F8) ] ──> [ 3. 选取起始工程 ] ──> [ 4. 点击开始导出 ]
```

1. **环境准备**：打开剪映专业版，停留在**项目草稿首页**。
2. **AI 扫描**：点击软件中的 `AI 识别首页草稿`，等待队列自动填满草稿列表。
3. **坐标向导（仅首次需设置）**：
   - 点击 `引导录制`，按照状态栏绿色提示依次按下 **F8**：
     - **第 1 步**：点开任意草稿，鼠标移至右上角【导出】→ 按 **F8**；
     - **第 2 步**：鼠标移至弹出窗口的【确认导出】按钮 → 按 **F8**；
     - **第 3 步**：鼠标移至【收起至首页】（或完成后的【关闭】）背景处 → 按 **F8**；
     - **第 4 步**：如果第 3 步用了收起至首页，直接按 **F9 跳过**；若第 3 步是关闭，鼠标移至剪辑界面左上角【关闭草稿】→ 按 **F8**。
4. **一键开跑**：在表格中点击想要开始的第一个草稿，点击 `开始批量导出`，接下来请泡杯咖啡，静待全部出片！

## 💡 注意事项与使用建议

> [!TIP]
> - **保持剪映窗口前台**：自动化批量点击期间，请不要遮挡或最小化剪映窗口，避免模拟鼠标误触其他窗口。
> - **关于字幕工具操作**：在执行“统一字体”或“解除隐藏”等直接修改草稿配置的操作时，**请务必确保剪映处于首页关闭草稿状态**，以防剪映内存数据覆盖本地修改。
> - **多屏缩放提示**：Windows 系统显示缩放推荐保持标准比例，如遇高分辨率屏，内置的自适应特征探测亦可完美兼容。
